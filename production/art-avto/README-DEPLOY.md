# ART-AVTO — сайт, исходники и архив для REG.RU

Сборка 17.11.2026. Главная страница `index.html`, стили/скрипты `assets/`, 11 оптимизированных под веб фотографий в `assets/auto-XX.webp`, политика `privacy.html`, SEO-страницы в `services/`.

## Запуск на REG.RU
1. Загрузите в корневой каталог сайта **содержимое** этого архива (а не внешнюю папку).
2. Подключите HTTPS (сертификат SSL) и назначьте реальный домен. После подтверждения домена заполните canonical, OG URL, sitemap.xml и robots.txt — сейчас домен не указан, не стоит публиковать выдуманные ссылки.
3. Уточните юридического оператора персональных данных и контакты, проверьте политику и согласие с юристом, актуализируйте по реальной схеме обработки.
4. Для настоящей отправки форм в Telegram/MAX нужно создать HTTPS обработчик (например, Cloudflare Worker), проверяющий входные данные и Turnstile, и задать адрес в `assets/config.js` → `requestEndpoint`. **Никогда не размещайте в публичном JS токены бота, секреты или чат-id без необходимости**.
5. Пока endpoint пуст, кнопка формы запускает почтовое приложение посетителя с подготовленной заявкой, НЕ отправляет данные автоматически. Кнопка телефона работает сразу.
6. Чтобы включить Яндекс.Метрику после настройки счётчика, задайте `yandexMetrikaId` в `assets/config.js`. До согласия счётчик не загружается. Цели, GTM и подтверждение корректности согласия проверяются отдельно.
7. Для кнопок Telegram/MAX нужны проверенные ссылки на аккаунт/бота Артура: сейчас они сознательно не выдуманы. Адрес автосервиса/часы работы не указаны, потому что заказчик их не прислал.

## GitHub Pages preview
При открытии на `github.io` JS проставляет meta robots noindex и показывает «Вернуться к проектам DashByte». Не воспринимайте staging как публичный домен для SEO.

## Юридическое оформление
Выкуп авто с ограничениями возможен только после проверки и при возможности законного оформления. Сайт не обещает безусловный выкуп, конкретные сроки или фиксированные цены. Реквизиты расчётного счёта в публичные исходники не добавлены.
