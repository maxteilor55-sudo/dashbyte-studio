# ART-AVTO — VOLT EDITION (v4)

Сайт выкупа автомобилей ART-AVTO, обновлён 17 ноября 2026. Актуальные исходники находятся в `production/art-avto/` репозитория `maxteilor55-sudo/dashbyte-studio`, готовый архив для REG.RU — в корне репозитория `art-avto-upload.zip`. Архив содержит то же содержимое, что и эта папка.

## Состав
- `index.html` — главная страница, адаптивная композиция с Toyota Land Cruiser, категории выкупа, этапы, фотоархив, три дополнительные услуги, контакты, FAQ, форма.
- `assets/site.css` — VOLT EDITION, собственная палитра charcoal/ivory/acid lime; анимации с поддержкой `prefers-reduced-motion`.
- `assets/site.js` — меню с сохранённой анимацией бургера в крестик, появление элементов, галерея, форма, cookies и прокрутка вверх.
- `assets/auto-*.webp` — **6 разных автомобилей, по одной фотографии каждой машины**, оптимизированные WebP, без EXIF.
- `privacy.html`, `services/*.html` — политика конфиденциальности и три SEO-страницы.
- `robots.txt`, `sitemap.template.xml` — подготовка индексации под подтверждённый домен.

## Адаптивность
Проверка Chromium 17.11.2026: ширина документа равна ширине экрана на 320, 360, 375, 390, 412, 430, 600, 768, 1024, 1440, 1920 CSS px. Проверены навигация, открытие меню, Escape, галерея, а также ширина страниц политики и услуг на 320–1440 px. На смартфоне блоки выкупа идут в две колонки, дополнительные услуги в компактных строках. Локальные тесты не подменяют ручную проверку в конкретных браузерах Telegram/MAX и на реальных устройствах.

## Публикация на REG.RU
1. Загрузите **содержимое** архива в корень сайта, не внешнюю папку. Включите HTTPS.
2. Когда будет известен домен, создайте настоящий `sitemap.xml` из `sitemap.template.xml`, замените шаблонный домен, добавьте `Sitemap:` в `robots.txt`, настройте canonical/OG URL. В GitHub Pages главная специально имеет `noindex`.
3. **Форма пока НЕ отправляет данные автоматически**: при пустом `assets/config.js` `requestEndpoint` формируется письмо `mailto:`. Для отправки напрямую в Telegram/MAX необходим HTTPS-обработчик и подтверждённые адресаты. Секреты и токены ботов нельзя хранить в публичном репозитории.
4. После создания счётчика добавьте его ID в `assets/config.js` (`yandexMetrikaId`), проверьте загрузку после согласия, настройте цели и правовую часть аналитики.
5. Подтвердите у заказчика, что ИП Евсеев Олег Эдуардович — оператор персональных данных сайта, и согласуйте текст политики. Реквизиты расчётного счёта публично не включены.
6. Telegram, MAX, юридический адрес, график работы не выдумываются: укажите только после получения подтверждённой информации.
