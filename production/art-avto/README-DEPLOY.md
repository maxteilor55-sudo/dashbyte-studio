# ART-AVTO — ATLAS 07 / AURORA GLASS (17 ноября 2026)

Новая самостоятельная редакционная концепция сайта ART-AVTO: темный морской графит, перламутровая мята и коралловые акценты, матовые Liquid Glass поверхности, анимации, кинематографическая обложка с Toyota Land Cruiser.

Главная услуга — выкуп автомобилей в Перми и крае. Дополнительно: эвакуатор, шиномонтаж, автосервис. Включены 6 реальных фотографий, отдельные SEO-страницы, политика конфиденциальности, HTML-форма и cookie-согласие.

## Публикация на REG.RU

В корень директории сайта загрузите СОДЕРЖИМОЕ архива `art-avto-upload.zip` (файл `index.html` должен оказаться в корне). Не загружайте вложенную папку `production/art-avto`.

**Важно:** форма до подключения HTTPS Worker открывает письмо через почтовое приложение посетителя. Без подтверждения отправки письма заявка не придёт. В `assets/config.js` необходимо указать рабочий `requestEndpoint` (сервер должен отправлять уведомление клиенту, Telegram токены не публикуйте), затем настроить Turnstile/Яндекс.Метрику с учётом согласия. Не показывайте форму как автоматически отправляющую, пока endpoint не проверен.

Фактический домен, юридические данные и адрес уточняются у заказчика. Пока на GitHub Pages предусмотрен noindex. Для собственной публикации заполните sitemap из `sitemap.template.xml`. Не указывайте несуществующие страницы и не добавляйте чужих рекламных обещаний.

GitHub — первоисточник: `production/art-avto/`. Архив в корне репозитория `art-avto-upload.zip` соответствует данной папке.
