# NOCTIS · Knowledge Engine 2.0 alpha

Самостоятельная мобильная HTML-альфа находится в [index.html](../index.html) внутри папки noctis-tarot-alpha. Она содержит встроенные данные и движок, поэтому её можно открыть напрямую в браузере без сервера.

## База знаний
- `arcana-78.ru.json`: **78** отдельных карт системы Rider–Waite–Smith: 22 старших и 56 младших арканов.
- Для каждой карты: исторически мотивированная символика иллюстрации, базовые значения и теневая сторона, собственные расширенные трактовки прямого и перевёрнутого положения, отношения, работа и проекты, совет и вопрос для самоанализа.
- `interpretation-engine.js`: алгоритм комбинирования, копия того же движка, который встроен в HTML. Не подключать этот файл одновременно с инлайн-движком, иначе будут повторные объявления.
- Любая пара разных карт: **78 × 77 / 2 = 3 003** уникальных сочетания, **12 012** состояний с четырьмя комбинациями ориентации. Интерпретация также зависит от позиции, выбранной темы, мастей, рангов, соотношения Старших и Младших арканов. Внутри движка есть 39 редакционно написанных специальных пар.
- Расклад на 1 / 3 / 5 карт: подробное описание каждой карты; при 3 картах — 3 связи, при 5 — все 10 пар, общий смысл и осторожный практический вывод.
- Русский текст пользовательского вопроса **не отправляется нейросети**: на данном этапе он используется только для распознавания тематики по ключевым словам. Реальный ИИ позже потребует серверного API и защиты ключей. Не помещать секретный ключ в HTML.

## Источники и принцип интерпретации
- Arthur Edward Waite, [The Pictorial Key to the Tarot](https://en.wikisource.org/wiki/Pictorial_Key_to_the_Tarot) (1910): исторические образы и трактовки прямого / перевёрнутого положения.
- [Llewellyn: Preparing to Read Tarot Card Combinations](https://www.llewellyn.com/journal/article/3090): сочетания карт не образуют фиксированного универсального словаря; контекст, позиции и соседние карты влияют на чтение.
- Иллюстрации текущей альфы используют изображения классической колоды через [tarot-api](https://github.com/sixseeds/tarot-api); пользовательский дизайн карт планируется отдельно.

**Важно:** новые описания — русские редакционные интерпретации, а не дословное копирование современных эзотерических сайтов. Алгоритмические сочетания — не канонические предсказания и не доказательство будущего. Не позиционировать их как факт, диагностику, финансовую рекомендацию или знание чужих мыслей.

## Правило разработки
Изменения словаря в `arcana-78.ru.json` и в инлайн-версии в `index.html` должны сохранять 78 уникальных ID. При изменении движка синхронизировать инлайн-копию и `interpretation-engine.js`. Последняя версия HTML в GitHub должна совпадать с раздаваемым клиенту файлом. Не менять другие проекты DashByte.
