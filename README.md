# DashByte v9.6 — SMART ENTRY

Внутри готовая статическая версия DashByte для GitHub Pages. Все ссылки на видео локальные.

## Файлы
- `index.html` — сайт, стили, изображения и встроенные клиентские проекты.
- `assets/hero-mobile.mp4` — видеообложка смартфона.
- `assets/hero-desktop.mp4` — видеообложка ПК/планшета/ТВ.
- `assets/showreel-original.mp4` — оригинальный ролик в Motion-разделе.

## Публикация
1. Создайте **новый публичный репозиторий** GitHub, например `dashbyte-site`.
2. Загрузите содержимое ЭТОЙ папки в корень репозитория (не папку целиком).
3. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
4. Дождитесь завершения публикации. Должна появиться HTTPS-ссылка вида `https://ИМЯ.github.io/dashbyte-site/`.
5. Проверьте сайт с мобильного и компьютера. В Telegram @BotFather выберите бота и настройте Menu Button (`/setmenubutton`) или Main Mini App на этот HTTPS-адрес.

Формы на сайте пока демонстрационные и не отправляют заявки на сервер. Ссылка на Telegram ведёт на `https://t.me/Reelog`. Индикатор доступности — демонстрационный, не отражает онлайн-статус API.

## Загрузка
Прелоадер ждёт загрузки страницы и первого кадра соответствующего видео. Если видео недоступно, предусмотрен 18-секундный аварийный таймаут с постером, чтобы не блокировать страницу.
